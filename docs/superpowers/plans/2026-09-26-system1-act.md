# System-1 Page Control (`Act`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An experimental, opt-in `Act` tool that runs Von 1.2 (a 395M ModernBERT "System One" decision model) on WebGPU inside the side panel to execute several low-stakes page-control steps locally between LLM calls.

**Architecture:** A Python exporter turns Von's PyTorch checkpoint into a quantized ONNX graph that computes Von's order-invariant attention masks in-graph; the maintainer hosts it on Hugging Face at a pinned revision. The extension downloads + SHA-256-verifies it into Cache Storage when the user flips a Settings → Experimental toggle, runs it with onnxruntime-web (WebGPU) in a dedicated worker behind a FIFO engine (the `pdfEngine.ts` pattern), and exposes a pure step-loop (`actLoop.ts`) as the `Act` tool, which executes every action through the *same* code path as `ControlPage` so every gate is unchanged.

**Tech Stack:** TypeScript/React/Vite (existing), `onnxruntime-web@1.30.0` (`/webgpu` entry), `@huggingface/tokenizers@0.2.0`, Vitest; Python 3.12 via `uv` (torch, transformers ≥ 5, von-sdk, onnx, onnxruntime, onnxconverter-common) for the exporter only.

**Spec:** `docs/superpowers/specs/2026-09-26-system1-act-design.md`

## Global Constraints

- Every agent tool routes through `requestApproval` where it acts; `Act` performs actions **only** via the extracted `controlStep` (Task 7), which contains ControlPage's point-of-no-return card, park, and origin-drift logic verbatim.
- `Act` never types/selects text other than a value from its `values` argument, verbatim; never navigates; sensitive (`el.sensitive`) elements are never candidates.
- `ACT_DEFAULT_STEPS = 6`, `ACT_MAX_STEPS = 8`, `ACT_CONFIDENCE = 0.6` (calibrated top probability).
- `VON_MAX_TOKENS = 4096` per packed sequence; over-length → typed error, never truncation.
- No WASM/CPU fallback: without a WebGPU adapter the tool is absent.
- Weights are pinned by `{repo, revision, manifestSha256}` in `src/system1/weightsManifest.ts`; never `main`. Every file SHA-256-verified before `cache.put`. Cache name `lychee-system1`; state key `system1State` in `chrome.storage.local`.
- ORT's `ort-wasm-simd-threaded.asyncify.wasm` (~27 MB) is **bundled** (MV3 remote-code ban) — accepted cost, even when the feature is off.
- `Settings.experimental?: { system1?: boolean }` — sparse, absent → off; always read through `system1Enabled()`.
- Use `npm run typecheck` (never `npx tsc`), `npm test`, `npm run build`.
- Commits: pathspec-scoped (`git commit -- <paths>`), no Co-Authored-By / generated-with trailers. Other sessions may be committing to `main` concurrently.
- **Code in this plan is an unverified sketch unless marked VERIFIED.** Run it; if reality disagrees, fix the code, not the test's intent. VERIFIED so far: JS tokenizer `@huggingface/tokenizers@0.2.0` loaded with Von's `tokenizer.json`+`tokenizer_config.json` produces ids identical to Python `tokenizers` on packed strings; `[CLS]`=50281 prepended, `[SEP]`=50282 appended, `[MASK]`=50284.

## Deviations from the spec (decided while planning)

1. **Masks built in-graph from `option_ids`** instead of passing two T×T float masks (at T=4096 those are 128 MB per call). Semantics identical to Von's `build_independent_option_masks`.
2. **fp16 is the fallback variant, not int8.** WebGPU EP supports `MatMulNBits` (q4) and fp16 well; dynamic int8 quantization is poorly supported there.
3. **Calibration:** instead of refitting (requires Von's JevBench data), the exporter gates on drift: a variant ships only if argmax agrees 100% and max |Δprob| ≤ 0.03 vs fp32 PyTorch across the probe suite, so Von's shipped `calibration_map` stays valid. q4 is tried first, then fp16.
4. **Act guidance lives in `Act`'s tool description**, not `TOOL_DISCLOSURE_NOTE` — the note is static and cache-marked; a conditional tool's guidance belongs with its schema.
5. **No busy/dialog flags in the premise** — `PageSnapshot` has none; `WAIT` remains a move.

```python
# scripts/export-von/export.py
# /// script
# requires-python = ">=3.12"
# dependencies = [
#   "von-sdk @ git+https://github.com/wfzyx/von@ca5d608fa79820d4e5388c9cb4c6a9b47a44a98c",
#   "torch>=2.4", "transformers>=5.0", "onnx>=1.17", "onnxruntime>=1.20",
#   "onnxconverter-common>=1.14", "huggingface_hub>=0.30", "numpy",
# ]
# ///
"""Export Von 1.2 to a browser-runnable ONNX graph.

The graph takes per-token option ids and builds Von's order-invariant masks
in-graph (see von.models.option_marker.build_independent_option_masks), so the
browser never uploads two TxT float masks per call.
"""
import hashlib, json, math, os, random, sys
import numpy as np
import torch
import onnx
import onnxruntime as ort
from huggingface_hub import hf_hub_download
from von.models.option_marker import OptionMarkerModel

REPO = "wfzyx/von"
REVISION = "5df8185a4f2327ad0a7cd117cc4f701ac557b9ae"
OUT = os.path.join(os.path.dirname(__file__), "out")
GOLDEN = os.path.join(os.path.dirname(__file__), "..", "..", "src", "system1", "__fixtures__", "von-golden.json")
MAX_TOKENS = 4096
NEG = -30000.0  # representable in fp16; exp() underflows to exactly 0 either way
PROB_TOL = 0.03


def load_reference():
    files = ["config.json", "model.safetensors", "option_marker.pt", "tokenizer.json",
             "tokenizer_config.json", "marker_calibration.json"]
    paths = {f: hf_hub_download(REPO, f, revision=REVISION) for f in files}
    ckpt_dir = os.path.dirname(paths["config.json"])
    model = OptionMarkerModel(base_model_id=ckpt_dir)
    model.load_state_dict(torch.load(paths["option_marker.pt"], map_location="cpu", weights_only=True), strict=True)
    model.eval()
    calib = json.load(open(paths["marker_calibration.json"]))
    assert calib.get("independent_options") is True, "exporter assumes Von >= 1.2"
    model.digit_split = bool(calib.get("digit_split", False))
    return model, calib, paths


class VonExport(torch.nn.Module):
    def __init__(self, model, sliding_window: int):
        super().__init__()
        self.encoder = model.encoder
        self.scorer = model.scorer
        self.w = sliding_window

    def forward(self, input_ids, option_ids, position_ids, marker_positions):
        oi = option_ids.unsqueeze(2)
        oj = option_ids.unsqueeze(1)
        qp = oi == -1
        kp = oj == -1
        allowed = (qp & kp) | (~qp & (kp | (oi == oj)))
        ar = torch.arange(input_ids.shape[1], device=input_ids.device)
        eye = (ar.unsqueeze(0) == ar.unsqueeze(1)).unsqueeze(0)
        full = allowed | eye
        pi = position_ids.unsqueeze(2)
        pj = position_ids.unsqueeze(1)
        sliding = (allowed & ((pi - pj).abs() <= self.w)) | eye
        zero = torch.zeros(full.shape, dtype=torch.float32, device=input_ids.device)
        fm = zero.masked_fill(~full, NEG).unsqueeze(1)
        sm = zero.masked_fill(~sliding, NEG).unsqueeze(1)
        hidden = self.encoder(
            input_ids=input_ids,
            attention_mask={"full_attention": fm, "sliding_attention": sm},
            position_ids=position_ids,
        ).last_hidden_state
        return self.scorer(hidden[0].index_select(0, marker_positions))


def plan_sequence(ids, mask_id):
    """Mirror of build_option_invariant_position_ids + option spans (batch 1, no padding)."""
    T = len(ids)
    markers = [i for i, t in enumerate(ids) if t == mask_id]
    last = T - 1  # trailing [SEP] stays prefix-class
    option_ids = [-1] * T
    position_ids = list(range(T))
    prefix_len = markers[0]
    for k, start in enumerate(markers):
        end = markers[k + 1] if k + 1 < len(markers) else last
        for j in range(start, end):
            option_ids[j] = k
            position_ids[j] = prefix_len + (j - start)
    return option_ids, position_ids, markers


def calibrate(logits, state_tokens, calib):
    logits = np.asarray(logits, dtype=np.float64)
    def softmax(x):
        e = np.exp(x - x.max()); return e / e.sum()
    m = calib.get("calibration_map")
    if m:
        p = softmax(logits); n = len(p)
        ent = float(-(p * np.log(np.clip(p, 1e-12, None))).sum() / math.log(n)) if n > 1 else 0.0
        raw = (m.get("bias", 0) * 1.0 + m.get("entropy", 0) * ent
               + m.get("log_tokens", 0) * (math.log10(max(state_tokens, 1)) / 4.0)
               + m.get("n_options", 0) * (n / 8.0))
        t = min(m.get("hi", 12.0), max(m.get("lo", 0.5), raw))
    else:
        t = float(calib.get("temperature", 1.0))
    return softmax(logits / max(t, 1e-4)).tolist()


def probe_suite():
    """Deterministic prompts spanning option counts 2..60 and lengths up to ~3k tokens."""
    rng = random.Random(7)
    roles = ["button", "link", "textbox", "select", "checkbox"]
    words = "cart checkout size colour blue red email name address next back search filter sort save cancel".split()
    cases = []
    for n in [2, 3, 5, 8, 13, 21, 34, 60]:
        opts = [f"[{i}] {rng.choice(roles)} '{rng.choice(words).title()} {rng.choice(words)}' → click" for i in range(n)]
        filler = " ".join(rng.choice(words) for _ in range(rng.choice([10, 200, 1500])))
        cases.append({
            "state": f"Goal: add the blue variant to the cart\nPage: Acme Shop (shop.example)\nNotes: {filler}",
            "instructions": "Which element should be used next to progress toward the goal?",
            "options": opts,
        })
    cases.append({"state": "Goal: sign up for the newsletter\nPage: Blog (blog.example)",
                  "instructions": "Decide the next browser move toward the goal.",
                  "options": ["Act on one of the visible page elements", "Scroll down to reveal more of the page",
                              "The page is still loading; wait", "The goal is already achieved", "The goal cannot be progressed here"]})
    return cases


def encode(tok, model, case):
    packed = model.pack_sequence(case["state"], case["instructions"], case["options"])
    ids = tok(packed)["input_ids"]
    assert len(ids) <= MAX_TOKENS, f"probe case too long: {len(ids)}"
    state_tokens = len(tok.encode(case["state"], add_special_tokens=False))
    return packed, ids, state_tokens


def reference_logits(model, ids, markers):
    with torch.no_grad():
        t = torch.tensor([ids])
        return model(input_ids=t, attention_mask=torch.ones_like(t), mask_positions=[markers],
                     independent_options=True)[0].float().numpy()


def onnx_logits(sess, ids, option_ids, position_ids, markers):
    return sess.run(["logits"], {
        "input_ids": np.array([ids], dtype=np.int64),
        "option_ids": np.array([option_ids], dtype=np.int64),
        "position_ids": np.array([position_ids], dtype=np.int64),
        "marker_positions": np.array(markers, dtype=np.int64),
    })[0].astype(np.float64)


def sha256(path):
    h = hashlib.sha256()
    with open(path, "rb") as f:
        for chunk in iter(lambda: f.read(1 << 20), b""):
            h.update(chunk)
    return h.hexdigest()


def main():
    os.makedirs(OUT, exist_ok=True)
    model, calib, paths = load_reference()
    tok = model.tokenizer
    w = int(model.encoder.config.sliding_window)
    print(f"[export] sliding_window={w} mask={model.mask_token_id}")

    # 1) The in-graph mask must reproduce Von's own forward exactly (fp32, PyTorch).
    wrapper = VonExport(model, w).eval()
    suite = probe_suite()
    encoded = []
    for case in suite:
        packed, ids, st = encode(tok, model, case)
        oid, pid, mk = plan_sequence(ids, model.mask_token_id)
        ref = reference_logits(model, ids, mk)
        with torch.no_grad():
            mine = wrapper(torch.tensor([ids]), torch.tensor([oid]), torch.tensor([pid]), torch.tensor(mk)).numpy()
        d = float(np.abs(ref - mine).max())
        assert d < 1e-3, f"wrapper diverges from Von reference by {d}"
        encoded.append((case, packed, ids, st, oid, pid, mk, ref))
    print("[export] wrapper == reference on all probes")

    # 2) Export fp32 (dynamic T and K).
    fp32 = os.path.join(OUT, "von_fp32.onnx")
    _, _, ids, _, oid, pid, mk, _ = encoded[3]
    torch.onnx.export(
        wrapper,
        (torch.tensor([ids]), torch.tensor([oid]), torch.tensor([pid]), torch.tensor(mk)),
        fp32,
        input_names=["input_ids", "option_ids", "position_ids", "marker_positions"],
        output_names=["logits"],
        dynamic_axes={"input_ids": {1: "T"}, "option_ids": {1: "T"}, "position_ids": {1: "T"},
                      "marker_positions": {0: "K"}, "logits": {0: "K"}},
        opset_version=18,
        dynamo=False,
    )

    # 3) Variants.
    from onnxruntime.quantization.matmul_nbits_quantizer import MatMulNBitsQuantizer
    q4 = os.path.join(OUT, "von_q4.onnx")
    qz = MatMulNBitsQuantizer(onnx.load(fp32), block_size=32, is_symmetric=True)
    qz.process()
    qz.model.save_model_to_file(q4, use_external_data_format=False)

    from onnxconverter_common import float16
    fp16 = os.path.join(OUT, "von_fp16.onnx")
    onnx.save(float16.convert_float_to_float16(onnx.load(fp32), keep_io_types=True), fp16)

    # 4) Parity gate + order invariance per variant.
    def gate(path):
        sess = ort.InferenceSession(path, providers=["CPUExecutionProvider"])
        worst = 0.0
        for case, packed, ids, st, oid, pid, mk, ref in encoded:
            got = onnx_logits(sess, ids, oid, pid, mk)
            p_ref, p_got = calibrate(ref, st, calib), calibrate(got, st, calib)
            if int(np.argmax(p_ref)) != int(np.argmax(p_got)):
                return False, f"argmax flip on {len(mk)}-option case"
            worst = max(worst, float(np.abs(np.array(p_ref) - np.array(p_got)).max()))
        # Order invariance: reverse the options of the 8-option case.
        case = encoded[3][0]
        rev = dict(case, options=list(reversed(case["options"])))
        _, ids2, _ = encode(tok, model, rev)
        o2, p2, m2 = plan_sequence(ids2, model.mask_token_id)
        a = onnx_logits(sess, *(encoded[3][2], encoded[3][4], encoded[3][5], encoded[3][6]))
        b = onnx_logits(sess, ids2, o2, p2, m2)[::-1]
        inv = float(np.abs(a - b).max())
        ok = worst <= PROB_TOL and inv < 1e-2
        return ok, f"max|Δp|={worst:.4f} invariance={inv:.5f}"

    chosen = None
    for name, path in [("q4", q4), ("fp16", fp16)]:
        ok, why = gate(path)
        print(f"[gate] {name}: {'PASS' if ok else 'FAIL'} {why}")
        if ok and chosen is None:
            chosen = (name, path)
    if chosen is None:
        sys.exit("[gate] no variant passes parity — STOP (see plan Task 1)")

    # 5) Ship files + manifest.
    name, path = chosen
    ship_model = os.path.join(OUT, f"model_{name}.onnx")
    os.replace(path, ship_model)
    for f in ["tokenizer.json", "tokenizer_config.json"]:
        with open(paths[f], "rb") as src, open(os.path.join(OUT, f), "wb") as dst:
            dst.write(src.read())
    von = {
        "model": calib.get("model_id", "von-1.2.0"),
        "maskTokenId": model.mask_token_id,
        "clsTokenId": tok.cls_token_id,
        "sepTokenId": tok.sep_token_id,
        "slidingWindow": w,
        "maxTokens": MAX_TOKENS,
        "digitSplit": model.digit_split,
        "temperature": float(calib.get("temperature", 1.0)),
        "calibrationMap": calib.get("calibration_map"),
    }
    json.dump(von, open(os.path.join(OUT, "von.json"), "w"), indent=2)
    files = [f"model_{name}.onnx", "tokenizer.json", "tokenizer_config.json", "von.json"]
    manifest = {
        "format": 1, "model": von["model"], "variant": name,
        "source": {"repo": REPO, "revision": REVISION},
        "files": [{"path": f, "bytes": os.path.getsize(os.path.join(OUT, f)),
                   "sha256": sha256(os.path.join(OUT, f))} for f in files],
    }
    json.dump(manifest, open(os.path.join(OUT, "manifest.json"), "w"), indent=2)
    print(f"[export] manifest sha256 = {sha256(os.path.join(OUT, 'manifest.json'))}")

    # 6) Golden fixture for the TS tests (first 3 cases + the move case; ids only, no weights).
    golden = {"model": von["model"], "maskTokenId": von["maskTokenId"], "calibration": {
        "temperature": von["temperature"], "calibrationMap": von["calibrationMap"]}, "cases": []}
    for case, packed, ids, st, oid, pid, mk, ref in [encoded[0], encoded[1], encoded[2], encoded[-1]]:
        golden["cases"].append({**case, "packed": packed, "ids": ids, "optionIds": oid, "positionIds": pid,
                                "markers": mk, "stateTokens": st, "logits": ref.tolist(),
                                "probs": calibrate(ref, st, calib)})
    os.makedirs(os.path.dirname(GOLDEN), exist_ok=True)
    json.dump(golden, open(GOLDEN, "w"))
    print(f"[export] wrote {GOLDEN}")


if __name__ == "__main__":
    main()
```

```ts
// src/system1/von.test.ts
import { describe, it, expect } from 'vitest'
import golden from './__fixtures__/von-golden.json'
import { calibrate, marginConfidence, packPrompt, planSequence, VonInputError } from './von'

const MASK = golden.maskTokenId

describe('packPrompt', () => {
  it('matches Von pack_sequence byte-for-byte on the golden cases', () => {
    for (const c of golden.cases) {
      expect(packPrompt(c.state, c.instructions, c.options, false)).toBe(c.packed)
    }
  })
  it('splits digit runs when digitSplit is on', () => {
    expect(packPrompt('year 2026', '', ['x'], true)).toBe('year 2 0 2 6 [SEP] [MASK] x')
  })
})

describe('planSequence', () => {
  it('reproduces Python option ids, position ids and markers', () => {
    for (const c of golden.cases) {
      const p = planSequence(c.ids, MASK, 4096)
```

```ts
// src/system1/von.ts
// Pure mirror of Von 1.2's option-marker input construction and calibration
// (von/models/option_marker.py, von/backends/option_marker_backend.py at
// ca5d608). Every function here has a Python twin; the golden fixture, produced
// by scripts/export-von/export.py from the real checkpoint, is what keeps the
// two from drifting. Change nothing here without regenerating it.

export interface CalibrationMap {
  bias?: number
  entropy?: number
  log_tokens?: number
  n_options?: number
  lo?: number
  hi?: number
}

export interface VonConfig {
  model: string
  maskTokenId: number
  clsTokenId: number
  sepTokenId: number
  slidingWindow: number
  maxTokens: number
  digitSplit: boolean
  temperature: number
  calibrationMap: CalibrationMap | null
}

export interface SequencePlan {
  optionIds: number[]
  positionIds: number[]
  markers: number[]
}

export class VonInputError extends Error {
  constructor(public code: 'too-long' | 'no-options', message: string) {
    super(message)
  }
}

const splitDigits = (s: string) => s.replace(/\d+/g, (run) => run.split('').join(' '))

/** Von's `pack_sequence`: `"{instructions} {state}" [SEP] [MASK] opt0 [MASK] opt1 …`. */
export function packPrompt(state: string, instructions: string, options: string[], digitSplit: boolean): string {
  const prefix = instructions ? `${instructions} ${state}`.trim() : state.trim()
  const opts = options.map((o) => `[MASK] ${o.trim()}`).join(' ')
  const packed = `${prefix} [SEP] ${opts}`
  return digitSplit ? splitDigits(packed) : packed
}

/**
 * Option spans + order-invariant position ids for one tokenized sequence
 * (batch 1, no padding). Each option's span runs from its [MASK] to the next
 * [MASK]; the LAST span stops before the trailing [SEP], which stays
 * prefix-class so no slot is special. Every span's positions restart at the
 * first marker's index (the prefix length).
 */
export function planSequence(ids: number[], maskTokenId: number, maxTokens: number): SequencePlan {
  if (ids.length > maxTokens)
    throw new VonInputError('too-long', `packed input is ${ids.length} tokens (max ${maxTokens})`)
  const markers: number[] = []
  ids.forEach((t, i) => {
    if (t === maskTokenId) markers.push(i)
  })
  if (markers.length === 0) throw new VonInputError('no-options', 'no [MASK] markers in packed input')
  const last = ids.length - 1
  const optionIds = ids.map(() => -1)
  const positionIds = ids.map((_, i) => i)
  const prefixLen = markers[0]
  markers.forEach((start, k) => {
    const end = k + 1 < markers.length ? markers[k + 1] : last
    for (let j = start; j < end; j++) {
      optionIds[j] = k
      positionIds[j] = prefixLen + (j - start)
    }
  })
  return { optionIds, positionIds, markers }
}

function softmax(xs: number[]): number[] {
  const m = Math.max(...xs)
  const e = xs.map((x) => Math.exp(x - m))
  const s = e.reduce((a, b) => a + b, 0)
  return e.map((x) => x / s)
}

/** Von's input-conditioned temperature, then softmax. Monotonic: never moves the argmax. */
export function calibrate(
  logits: number[],
  stateTokens: number,
  cfg: { temperature: number; calibrationMap: CalibrationMap | null },
): number[] {
  const m = cfg.calibrationMap
  let t = cfg.temperature
  if (m) {
    const p = softmax(logits)
    const n = p.length
    const ent = n > 1 ? -p.reduce((a, x) => a + x * Math.log(Math.max(x, 1e-12)), 0) / Math.log(n) : 0
    const raw =
      (m.bias ?? 0) +
      (m.entropy ?? 0) * ent +
      (m.log_tokens ?? 0) * (Math.log10(Math.max(stateTokens, 1)) / 4) +
      (m.n_options ?? 0) * (n / 8)
    t = Math.min(m.hi ?? 12, Math.max(m.lo ?? 0.5, raw))
  }
  const denom = Math.max(t, 1e-4)
  return softmax(logits.map((x) => x / denom))
}

/** TypeSafe's confidence: (n·pmax − 1)/(n − 1), anchored to the 1/n chance baseline. */
export function marginConfidence(probs: number[]): number {
  const n = probs.length
  if (n <= 1) return 1
  const c = (n * Math.max(...probs) - 1) / (n - 1)
  return Math.round(Math.max(0, Math.min(1, c)) * 1000) / 1000
}
```

```ts
// src/system1/weights.ts
// Download, verify and cache the System-1 model. Panel-resident (the SW never
// imports it). Integrity model: the pinned manifest hash authenticates the
// manifest; the manifest's per-file hashes authenticate each file; nothing is
// cache.put() before its hash matches, and readiness is written only after
// every file verified — a partial download is never "ready".
import { WEIGHTS_PIN, type WeightsPin } from './weightsManifest'

export type { WeightsPin }
export const CACHE_NAME = 'lychee-system1'
export const STATE_KEY = 'system1State'

export interface WeightsFile { path: string; bytes: number; sha256: string }
export interface WeightsManifest { format: 1; model: string; variant: string; files: WeightsFile[] }
export interface System1State { revision: string; variant: string; bytes: number; readyAt: number }
export type DownloadProgress =
  | { phase: 'manifest' }
  | { phase: 'file'; path: string; received: number; overallReceived: number; overallTotal: number }
  | { phase: 'verifying'; path: string }

export interface WeightsDeps {
  fetch: typeof fetch
  cache: Pick<Cache, 'put' | 'match' | 'delete'>
  onProgress?: (p: DownloadProgress) => void
  signal?: AbortSignal
}

export const fileUrl = (pin: WeightsPin, path: string) =>
  `https://huggingface.co/${pin.repo}/resolve/${pin.revision}/${path}`

const HEX64 = /^[0-9a-f]{64}$/
const SAFE_PATH = /^[A-Za-z0-9_.-]+$/

export function parseManifest(json: unknown): WeightsManifest {
  const m = json as Partial<WeightsManifest>
  if (!m || m.format !== 1 || typeof m.model !== 'string' || typeof m.variant !== 'string' || !Array.isArray(m.files))
    throw new Error('model manifest has an unexpected shape')
  for (const f of m.files) {
    if (!f || typeof f.path !== 'string' || !SAFE_PATH.test(f.path) || f.path.includes('..'))
      throw new Error('model manifest lists an unsafe path')
    if (typeof f.bytes !== 'number' || f.bytes < 0 || typeof f.sha256 !== 'string' || !HEX64.test(f.sha256))
      throw new Error(`model manifest entry ${f.path} is malformed`)
  }
  return m as WeightsManifest
}

async function sha256Hex(bytes: Uint8Array): Promise<string> {
  const d = await crypto.subtle.digest('SHA-256', bytes)
  return [...new Uint8Array(d)].map((b) => b.toString(16).padStart(2, '0')).join('')
}

async function readAll(res: Response, onChunk: (n: number) => void, signal?: AbortSignal): Promise<Uint8Array> {
  if (!res.body) return new Uint8Array(await res.arrayBuffer())
  const reader = res.body.getReader()
  const chunks: Uint8Array[] = []
  let total = 0
  for (;;) {
    if (signal?.aborted) {
      await reader.cancel()
      throw new DOMException('Download cancelled', 'AbortError')
    }
    const { done, value } = await reader.read()
    if (done) break
    chunks.push(value)
    total += value.length
    onChunk(value.length)
  }
  const out = new Uint8Array(total)
  let o = 0
  for (const c of chunks) { out.set(c, o); o += c.length }
  return out
}

export async function downloadWeights(pin: WeightsPin, deps: WeightsDeps): Promise<System1State> {
  if (!pin.repo || !pin.revision || !pin.manifestSha256)
    throw new Error('The System-1 model has not been published yet (empty WEIGHTS_PIN).')
  const { fetch: f, cache, onProgress, signal } = deps
  signal?.throwIfAborted()
  onProgress?.({ phase: 'manifest' })
  const mRes = await f(fileUrl(pin, 'manifest.json'), { signal })
  if (!mRes.ok) throw new Error(`manifest download failed (${mRes.status})`)
  const mBytes = new Uint8Array(await mRes.arrayBuffer())
  if ((await sha256Hex(mBytes)) !== pin.manifestSha256) throw new Error('manifest hash does not match the pinned value')
  const manifest = parseManifest(JSON.parse(new TextDecoder().decode(mBytes)))
  const overallTotal = manifest.files.reduce((a, x) => a + x.bytes, 0)
  let overallReceived = 0
  for (const file of manifest.files) {
    signal?.throwIfAborted()
    const res = await f(fileUrl(pin, file.path), { signal })
    if (!res.ok) throw new Error(`${file.path} download failed (${res.status})`)
    let received = 0
    const bytes = await readAll(res, (n) => {
      received += n
      overallReceived += n
      onProgress?.({ phase: 'file', path: file.path, received, overallReceived, overallTotal })
    }, signal)
    onProgress?.({ phase: 'verifying', path: file.path })
    if (bytes.length !== file.bytes || (await sha256Hex(bytes)) !== file.sha256)
      throw new Error(`${file.path} failed its integrity check`)
    await cache.put(fileUrl(pin, file.path), new Response(bytes))
  }
  // The manifest goes in last: its presence is what verifyCached/loadCachedManifest key off.
  await cache.put(fileUrl(pin, 'manifest.json'), new Response(mBytes))
  return { revision: pin.revision, variant: manifest.variant, bytes: overallTotal, readyAt: Date.now() }
}

export async function loadCachedManifest(pin: WeightsPin, cache: Pick<Cache, 'match'>): Promise<WeightsManifest | null> {
  const r = await cache.match(fileUrl(pin, 'manifest.json'))
  if (!r) return null
  try { return parseManifest(await r.json()) } catch { return null }
}

/** Presence check only (hashes were verified on the way in; re-hashing 400 MB per boot is not worth it). */
export async function verifyCached(pin: WeightsPin, manifest: WeightsManifest, cache: Pick<Cache, 'match'>): Promise<boolean> {
  for (const f of manifest.files) if (!(await cache.match(fileUrl(pin, f.path)))) return false
  return true
}

export async function readState(): Promise<System1State | null> {
  const got = await chrome.storage.local.get(STATE_KEY)
  const s = got[STATE_KEY] as System1State | undefined
  return s && s.revision === WEIGHTS_PIN.revision ? s : null
}

export async function writeState(s: System1State): Promise<void> {
  await chrome.storage.local.set({ [STATE_KEY]: s })
}

export async function deleteWeights(): Promise<void> {
  await chrome.storage.local.remove(STATE_KEY)
  await caches.delete(CACHE_NAME)
}
```

```ts
async function boot(m: Extract<System1WorkerRequest, { type: 'init' }>) {
  ort.env.wasm.wasmPaths = { wasm: m.wasmUrl }
  ort.env.wasm.numThreads = 1 // extension pages are not crossOriginIsolated
  const [model, tj, tc, c] = await Promise.all([
    cached(m.modelUrl).then((r) => r.arrayBuffer()),
    cached(m.tokenizerUrl).then((r) => r.json()),
    cached(m.tokenizerConfigUrl).then((r) => r.json()),
    cached(m.configUrl).then((r) => r.json()),
  ])
  tokenizer = new Tokenizer(tj, tc)
  cfg = c as VonConfig
  session = await ort.InferenceSession.create(new Uint8Array(model), {
    executionProviders: ['webgpu'],
    graphOptimizationLevel: 'all',
  })
}

async function scoreQuestion(state: string, q: DecideRequest['questions'][string]): Promise<DecideAnswer> {
  const keys = Object.keys(q.options)
  const packed = packPrompt(state, q.instructions, keys.map((k) => q.options[k]), cfg!.digitSplit)
  const ids = tokenizer!.encode(packed).ids
  const plan = planSequence(ids, cfg!.maskTokenId, cfg!.maxTokens)
  if (plan.markers.length !== keys.length)
    throw new VonInputError('no-options', `an option text contains a literal [MASK] (${plan.markers.length} ≠ ${keys.length})`)
  const T = ids.length
  const i64 = (xs: number[]) => BigInt64Array.from(xs, (x) => BigInt(x))
  const out = await session!.run({
    input_ids: new ort.Tensor('int64', i64(ids), [1, T]),
    option_ids: new ort.Tensor('int64', i64(plan.optionIds), [1, T]),
    position_ids: new ort.Tensor('int64', i64(plan.positionIds), [1, T]),
    marker_positions: new ort.Tensor('int64', i64(plan.markers), [plan.markers.length]),
  })
  const logits = Array.from(out.logits.data as Float32Array)
  const stateTokens = tokenizer!.encode(state, { add_special_tokens: false }).ids.length
  const probs = calibrate(logits, stateTokens, cfg!)
  let best = 0
  probs.forEach((p, i) => { if (p > probs[best]) best = i })
  return {
    choice: keys[best],
    probabilities: Object.fromEntries(keys.map((k, i) => [k, Math.round(probs[i] * 1e4) / 1e4])),
    top: probs[best],
    confidence: marginConfidence(probs),
  }
}

self.onmessage = async (e: MessageEvent<System1WorkerRequest>) => {
  const m = e.data
  if (!m || typeof m !== 'object') return
  if (m.type === 'init') {
    if (session) return post({ type: 'ready' })
    try {
      await boot(m)
      post({ type: 'ready' })
    } catch (err) {
      session = null
      post({ type: 'boot-failed', message: err instanceof Error ? err.message : String(err) })
    }
    return
  }
  if (m.type === 'decide') {
    const t0 = performance.now()
    try {
      const answers: Record<string, DecideAnswer> = {}
      for (const [key, q] of Object.entries(m.req.questions)) answers[key] = await scoreQuestion(m.req.state, q)
      const result: DecideResult = { answers, ms: Math.round(performance.now() - t0) }
      post({ type: 'result', id: m.id, result })
    } catch (err) {
      post({
        type: 'failed', id: m.id,
        message: err instanceof Error ? err.message : String(err),
        code: err instanceof VonInputError ? err.code : undefined,
      })
    }
  }
}
```

```ts
// src/system1/engine.ts
// Panel-side client for the System-1 worker — the pdfEngine.ts analog. One
// module Worker, booted lazily, FIFO-serialized (one WebGPU session; a queued
// call's timeout starts when it actually begins), rebuilt if a round trip
// wedges. `healthy` goes false on a boot failure or wedge so resolveSystem1
// stops offering Act until a later boot succeeds.
import wasmUrl from 'onnxruntime-web/ort-wasm-simd-threaded.asyncify.wasm?url'
import { WEIGHTS_PIN, fileUrl, loadCachedManifest, CACHE_NAME } from './weights'
import type { DecideRequest, DecideResult, System1WorkerReply, System1WorkerRequest } from './protocol'

// Reading ~400 MB from Cache Storage and compiling WebGPU pipelines, cold.
const BOOT_TIMEOUT_MS = 120_000
const DECIDE_TIMEOUT_MS = 15_000

interface Pending { resolve: (r: DecideResult) => void; reject: (e: Error) => void; timer: number }

export class System1Engine {
  private worker: Worker | null = null
  private ready: Promise<void> | null = null
  private onReady: ((err?: Error) => void) | null = null
  private pending = new Map<string, Pending>()
  private queue: Promise<void> = Promise.resolve()
  private _healthy = true

  get healthy() { return this._healthy }

  private listener = (e: MessageEvent<System1WorkerReply>) => {
    const m = e.data
    if (!m || typeof m !== 'object') return
    if (m.type === 'ready') { this.onReady?.(); this.onReady = null; return }
    if (m.type === 'boot-failed') { this.onReady?.(new Error(m.message)); this.onReady = null; return }
    const p = this.pending.get(m.id)
    if (!p) return
    this.pending.delete(m.id)
    clearTimeout(p.timer)
    if (m.type === 'result') p.resolve(m.result)
    else p.reject(Object.assign(new Error(m.message), { code: m.code }))
  }

  async decide(req: DecideRequest): Promise<DecideResult> {
    const previous = this.queue
    let release!: () => void
    this.queue = new Promise((r) => { release = r })
    await previous
    try {
      await this.ensure()
      const id = crypto.randomUUID()
      return await new Promise<DecideResult>((resolve, reject) => {
        const timer = window.setTimeout(() => {
          this.pending.delete(id)
          this._healthy = false
          this.destroy()
          reject(new Error('the System-1 engine stopped responding and was reset'))
        }, DECIDE_TIMEOUT_MS)
        this.pending.set(id, { resolve, reject, timer })
        this.worker!.postMessage({ type: 'decide', id, req } satisfies System1WorkerRequest)
      })
    } finally {
      release()
    }
  }

  private ensure() {
    if (!this.ready) this.ready = this.boot()
    return this.ready
  }

  private async boot() {
    try {
      const manifest = await loadCachedManifest(WEIGHTS_PIN, await caches.open(CACHE_NAME))
      if (!manifest) throw new Error('the System-1 model is not downloaded')
      const model = manifest.files.find((f) => f.path.endsWith('.onnx'))
      if (!model) throw new Error('the model manifest lists no .onnx file')
      const worker = new Worker(chrome.runtime.getURL('system1Worker.js'), { type: 'module' })
      worker.addEventListener('message', this.listener)
      worker.addEventListener('error', (e) => { this.onReady?.(new Error(e.message || 'System-1 worker failed to start')); this.onReady = null })
      this.worker = worker
      await new Promise<void>((resolve, reject) => {
        const t = window.setTimeout(() => reject(new Error('the System-1 engine did not start in time')), BOOT_TIMEOUT_MS)
        this.onReady = (err) => { clearTimeout(t); err ? reject(err) : resolve() }
        worker.postMessage({
          type: 'init',
          wasmUrl: new URL(wasmUrl, location.href).href,
          modelUrl: fileUrl(WEIGHTS_PIN, model.path),
          tokenizerUrl: fileUrl(WEIGHTS_PIN, 'tokenizer.json'),
          tokenizerConfigUrl: fileUrl(WEIGHTS_PIN, 'tokenizer_config.json'),
          configUrl: fileUrl(WEIGHTS_PIN, 'von.json'),
        } satisfies System1WorkerRequest)
      })
      this._healthy = true
    } catch (err) {
      this._healthy = false
      this.destroy()
      throw err
    }
  }

  private destroy() {
    this.worker?.terminate()
    this.worker = null
    this.ready = null
    this.onReady = null
    for (const p of this.pending.values()) { clearTimeout(p.timer); p.reject(new Error('the System-1 engine was torn down')) }
    this.pending.clear()
  }
}

let engine: System1Engine | null = null
export function getSystem1Engine(): System1Engine {
  if (!engine) engine = new System1Engine()
  return engine
}
```

```ts
// src/system1/runtime.ts
// Whether this chain gets an Act tool at all: toggle on, weights ready for the
// pinned revision and present in the cache, a WebGPU adapter, and an engine
// that has not failed. Any "no" → undefined → the tool is never built.
import type { Settings } from '../data/settings'
import { system1Enabled } from '../data/settings'
import { getSystem1Engine } from './engine'
import type { DecideRequest, DecideResult } from './protocol'
import { CACHE_NAME, WEIGHTS_PIN, loadCachedManifest, readState, verifyCached } from './weights'

export interface System1Runtime { decide(req: DecideRequest): Promise<DecideResult> }

let adapterProbe: Promise<boolean> | null = null
export function hasWebGpu(): Promise<boolean> {
  if (!adapterProbe) {
    const gpu = (navigator as Navigator & { gpu?: { requestAdapter(): Promise<unknown> } }).gpu
    adapterProbe = gpu ? gpu.requestAdapter().then((a) => a != null, () => false) : Promise.resolve(false)
  }
  return adapterProbe
}

export async function resolveSystem1(settings: Settings): Promise<System1Runtime | undefined> {
  try {
    if (!system1Enabled(settings)) return undefined
    if (!(await readState())) return undefined
    const cache = await caches.open(CACHE_NAME)
    const manifest = await loadCachedManifest(WEIGHTS_PIN, cache)
    if (!manifest || !(await verifyCached(WEIGHTS_PIN, manifest, cache))) return undefined
    if (!(await hasWebGpu())) return undefined
    const engine = getSystem1Engine()
    if (!engine.healthy) return undefined
    return { decide: (req) => engine.decide(req) }
  } catch {
    return undefined
  }
}
```

```ts
    calls.push(req)
    if ('move' in req.questions) step++

    const answers: DecideResult['answers'] = {}
    for (const key of Object.keys(req.questions)) {

      const [choice, p] = Array.isArray(v) ? v : [v, 0.9]
      answers[key] = { choice, probabilities: { [choice]: p }, top: p, confidence: p }
    }
    return { answers, ms: 5 }

  return { decide, calls }
```

```ts
// src/system1/actLoop.ts
// The Act tool's step loop, pure over injected effects. Von chooses from a
// CLOSED set each step — a move, an on-screen element, a supplied value key —
// and never produces text, a URL or a navigation. Execution is delegated to
// `execute`, which in production is ControlPage's own controlStep: every
// point-of-no-return card, park and origin-drift check applies unchanged.
import type { IndexedElement } from '../platform/domIndex'
import type { ControlSpec } from '../tools/pageControl'
import type { DecideQuestion, DecideRequest, DecideResult } from './protocol'
import type { PageSnapshot } from '../platform/domIndex'

export const ACT_DEFAULT_STEPS = 6
export const ACT_MAX_STEPS = 8
export const ACT_CONFIDENCE = 0.6

export type ActStatus = 'done' | 'blocked' | 'uncertain' | 'denied' | 'drifted' | 'repeat' | 'aborted' | 'capped' | 'error' | 'parked'
export type ExecOutcome =
  | { kind: 'ok'; elements: string }
  | { kind: 'denied' }
  | { kind: 'parked'; note: string }
  | { kind: 'drifted'; message: string; elements?: string }
  | { kind: 'error'; message: string }
export interface ActStep { action: ControlSpec['action']; index?: number; label?: string; p: number; ms: number }
export interface ActResult {
  status: ActStatus
  steps: ActStep[]
  candidates?: { index: number; label: string; p: number }[]
  message?: string
  elements?: string
}
export interface ActDeps {
  snapshot(): Promise<PageSnapshot>
  decide(req: DecideRequest): Promise<DecideResult>
  execute(spec: ControlSpec): Promise<ExecOutcome>
  aborted(): boolean
}

const TEXT_INPUT = new Set(['', 'text', 'email', 'search', 'tel', 'url', 'number', 'date', 'time', 'datetime-local', 'month', 'week'])

export function opFor(el: IndexedElement): 'click' | 'type' | 'select' {
  const tag = el.tag.toLowerCase()
  if (tag === 'select') return 'select'
  if (tag === 'textarea') return 'type'
  if (tag === 'input' && TEXT_INPUT.has((el.type ?? '').toLowerCase())) return 'type'
  if (el.role === 'textbox' || el.role === 'searchbox') return 'type'
  return 'click'
}

const clip = (s: string, n: number) => (s.length > n ? `${s.slice(0, n - 1)}…` : s)
const describe = (el: IndexedElement, op: string) => {
  const kind = el.role || (el.tag === 'input' ? `${el.type || 'text'} field` : el.tag)
  const cur = el.value ? ` (currently "${clip(el.value, 30)}")` : ''
  return `[${el.index}] ${kind} "${clip(el.name || '(unnamed)', 80)}"${cur} → ${op}`
}

const MOVES: Record<string, string> = {
  act: 'Act on one of the visible page elements to make progress toward the goal.',
  scroll_down: 'Scroll down: the element needed next is not visible yet.',
  WAIT: 'The page is still loading or changing; wait for it to settle.',
  DONE: 'The goal is already achieved on this page.',
  BLOCKED: 'The goal cannot be progressed here (login, captcha, a missing control, or information that was not provided).',
}

export async function runActLoop(
  input: { goal: string; values?: Record<string, string>; maxSteps?: number },
  deps: ActDeps,
): Promise<ActResult> {
  const values = input.values ?? {}
  const valueKeys = Object.keys(values)
  const cap = Math.max(1, Math.min(ACT_MAX_STEPS, input.maxSteps ?? ACT_DEFAULT_STEPS))
  const steps: ActStep[] = []
  let lastElements: string | undefined
  let prev: { action: string; index?: number } | null = null

  for (let n = 0; n < cap; n++) {
    if (n > 0 && deps.aborted()) return { status: 'aborted', steps, elements: lastElements }
    let snap: PageSnapshot
    try { snap = await deps.snapshot() } catch (err) {
      return { status: 'error', steps, message: `could not read the page: ${err instanceof Error ? err.message : String(err)}` }
    }
    const candidates = snap.elements.filter((el) => {
      if (el.sensitive) return false
      const op = opFor(el)
      return op === 'click' || valueKeys.length > 0
    })
    const done = steps.map((s, i) => `${i + 1}. ${s.action}${s.label ? ` "${s.label}"` : ''}`).join('; ') || 'nothing yet'
    const state = [
      `Goal: ${input.goal}`,
      `Page: ${snap.title} (${snap.origin})`,
      `Done so far: ${done}`,
      valueKeys.length ? `Provided values: ${valueKeys.join(', ')}` : 'Provided values: none',
    ].join('\n')

    const questions: Record<string, DecideQuestion> = {
      move: { instructions: 'Decide the next browser move toward the goal.', options: { ...MOVES } },
    }
    if (candidates.length === 0) delete questions.move.options.act
    let result: DecideResult
    let ms = 0
    try {
      result = await deps.decide({ state, questions })
      ms += result.ms
    } catch (err) {
      return { status: 'error', steps, message: `System-1 engine failed: ${err instanceof Error ? err.message : String(err)}` }
    }
    const move = result.answers.move
    if (move.top < ACT_CONFIDENCE) return { status: 'uncertain', steps, message: `unsure of the next move (p=${move.top.toFixed(2)})`, elements: snap.text }
    if (move.choice === 'DONE') return { status: 'done', steps, elements: snap.text }
    if (move.choice === 'BLOCKED') return { status: 'blocked', steps, elements: snap.text }

    let spec: ControlSpec
    let label: string | undefined
    let p = move.top
    if (move.choice === 'scroll_down') spec = { action: 'scroll', direction: 'down' }
    else if (move.choice === 'WAIT') spec = { action: 'wait', timeoutMs: 3000 }
    else {
      const targetQ: Record<string, DecideQuestion> = {
        target: {
          instructions: 'Which element should be used next to progress toward the goal?',
          options: Object.fromEntries(candidates.map((el) => [String(el.index), describe(el, opFor(el))])),
        },
      }
      let t: DecideResult
      try { t = await deps.decide({ state, questions: targetQ }) } catch (err) {
        return { status: 'error', steps, message: `System-1 engine failed: ${err instanceof Error ? err.message : String(err)}` }
      }
      ms += t.ms
      const ans = t.answers.target
      if (ans.top < ACT_CONFIDENCE) {
        const ranked = Object.entries(ans.probabilities).sort((a, b) => b[1] - a[1]).slice(0, 3)
        const byIndex = new Map(candidates.map((el) => [String(el.index), el]))
        return {
          status: 'uncertain', steps, elements: snap.text,
          message: `unsure which element to use (p=${ans.top.toFixed(2)})`,
          candidates: ranked.map(([k, pr]) => ({ index: Number(k), label: byIndex.get(k)?.name ?? '', p: pr })),
        }
      }
      const el = candidates.find((c) => String(c.index) === ans.choice)!
      label = clip(el.name || '(unnamed)', 60)
      p = Math.min(p, ans.top)
      const op = opFor(el)
      if (op === 'click') spec = { action: 'click', index: el.index }
      else {
        let v: DecideResult
        try {
          v = await deps.decide({ state, questions: { value: {
            instructions: `Which provided value belongs in ${describe(el, op)}?`,
            options: Object.fromEntries(valueKeys.map((k) => [k, `${k}: ${clip(values[k], 40)}`])),
          } } })
        } catch (err) {
          return { status: 'error', steps, message: `System-1 engine failed: ${err instanceof Error ? err.message : String(err)}` }
        }
        ms += v.ms
        if (v.answers.value.top < ACT_CONFIDENCE)
          return { status: 'uncertain', steps, elements: snap.text, message: `unsure which value belongs in "${label}"` }
        p = Math.min(p, v.answers.value.top)
        const text = values[v.answers.value.choice]
        spec = op === 'type' ? { action: 'type', index: el.index, text, clear: true } : { action: 'select', index: el.index, value: text }
      }
    }

    if (prev && prev.action === spec.action && prev.index === spec.index && spec.index !== undefined)
      return { status: 'repeat', steps, elements: snap.text, message: `would repeat ${spec.action} on [${spec.index}]` }

    const out = await deps.execute(spec)
    if (out.kind === 'denied') return { status: 'denied', steps }
    if (out.kind === 'parked') return { status: 'parked', steps, message: out.note }
    if (out.kind === 'drifted') return { status: 'drifted', steps, message: out.message, elements: out.elements }
    if (out.kind === 'error') return { status: 'error', steps, message: out.message }
    steps.push({ action: spec.action, index: spec.index, label, p: Math.round(p * 100) / 100, ms })
    lastElements = out.elements
    prev = { action: spec.action, index: spec.index }
  }
  return { status: 'capped', steps, elements: lastElements }
}
```
